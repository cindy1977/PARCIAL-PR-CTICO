# Examen práctico de GitHub Básico — Flujo colaborativo

## Objetivo
Demostrar el flujo básico de trabajo con Git y GitHub:

1. Crear una rama a partir de `main`.
2. Modificar información del proyecto.
3. Ejecutar `git add`.
4. Ejecutar `git commit`.
5. Ejecutar `git push`.
6. Crear un Pull Request hacia `main`.
7. Revisar y realizar el merge.
8. Actualizar el repositorio local con `git pull`.

## Contexto
Este repositorio simula el sitio de un pequeño proyecto académico llamado **Campus Digital**.

La persona evaluada debe realizar el cambio solicitado en su propia rama sin modificar directamente `main`.

## Regla importante
El cambio debe poder identificarse claramente en GitHub mediante:
- nombre de la rama;
- commit;
- archivos modificados;
- Pull Request;
- merge;
- actualización final mediante `git pull`.

Consulta `EXAMEN_PRACTICO.md` para las instrucciones y `evaluacion/RUBRICA.md` para los criterios de evaluación.
